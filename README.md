# ebook-ia-Master-Build-Forja-do-Hardware
Projeto de eBook criado com IA (ChatGPT/Midjourney)
📘 Título do eBook – Criado com IA (ChatGPT + Midjourney)

Este repositório contém todo o processo de criação do meu eBook desenvolvido com o uso de Inteligência Artificial, seguindo uma metodologia organizada e transparente.
Aqui você encontrará:

Os prompts usados para gerar texto e imagens

A estrutura do projeto

O eBook final em PDF

Todo o fluxo para criar um livro usando ferramentas de IA

🧠 Ferramentas Utilizadas

ChatGPT (GPT-5.1) — para criação de conteúdo, capítulos, revisão e estruturação

Midjourney — para criação de imagens e capa

Canva — para diagramação final do eBook (opcional)

GitHub — para organização e entrega do projeto

✨ Descrição do Projeto

Este projeto demonstra como criar um eBook do zero usando IA.
A ideia é mostrar um fluxo completo, desde o desenvolvimento do tema até a geração final do PDF:

Definição do tema

Criação da estrutura do livro

Geração dos capítulos

Revisão e melhoria do conteúdo

Criação da capa e imagens

Formatação final e exportação

Todos os prompts usados estão dentro da pasta /prompts.
